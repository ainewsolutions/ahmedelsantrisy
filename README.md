## النشر على GitHub Pages
1. ارفع **محتويات** هذا المجلد إلى مستودع جديد (index.html في جذر المستودع).
2. Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)` ثم Save.
3. سيعمل الموقع على: `https://USERNAME.github.io/REPO/`
